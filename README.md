# 뛰뛰빵빵 IR / 사업계획서 프로젝트

한밭수목원을 중심으로 기획한 장소특화형 야외 방탈출 관광콘텐츠 **「뛰뛰빵빵」**의 사업계획서와 IR 피치 자료를 정리하는 저장소입니다.

## 작업 원칙

1. 현재 단계에서는 **사업계획서 문서화**를 우선합니다.
2. 각 항목은 근거자료와 수치를 충분히 축적한 뒤 압축합니다.
3. 이후 각 문서를 기반으로 12장 IR 피치덱으로 전환합니다.
4. 사실·통계·시장자료는 출처와 기준연도를 반드시 기록합니다.
5. 아직 검증되지 않은 수치는 `가정`, `목표`, `추정`으로 구분합니다.
