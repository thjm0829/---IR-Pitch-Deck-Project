# 07. 아이템 설명

## 이 문서의 목적
뛰뛰빵빵에서 고객이 실제로 구매하고 사용하는 상품이 무엇인지 구체화한다. 미션키트의 구성, 스토리 콘텐츠, 문제 설계, 체크포인트와 운영 방식, MVP 범위를 하나의 상품 구조로 정리한다.

뛰뛰빵빵의 핵심 상품은 단순한 문제지나 관광 안내책자가 아니라, 참가자가 실제 공간을 하나의 게임 세계로 경험할 수 있도록 구성한 **아날로그 야외 방탈출 미션키트와 장소 기반 스토리 콘텐츠**이다.

참가자는 종이 지도, 미션북, 단서 카드, 암호도구 등을 직접 손에 들고 한밭수목원을 이동한다. 각각의 문제는 실제 장소와 연결되며, 현장에 직접 방문하고 주변을 관찰해야 해결할 수 있도록 설계한다.

## 7.1 상품 및 미션키트 구성

초기 대표상품은 **2~4인이 함께 이용하는 하나의 미션키트**를 기본 단위로 검토한다. `[ASSUMPTION]`

### 기본 상품 구성 예시
- 한밭수목원 전용 게임 지도
- 스토리 및 미션북
- 기록용 펜 또는 연필
- 단서 카드
- 암호표 또는 해독판
- 장소별 미션 카드
- 단계별 힌트 카드 또는 봉인형 힌트
- FINAL 카드 또는 엔딩 봉투
- 향후 제휴 빵집·카페 쿠폰 및 후속 관광 안내

키트는 참가자가 이동하면서 쉽게 펼치고 기록할 수 있도록 가볍고 휴대성이 높은 형태로 제작한다.

전자기기나 별도의 장비가 없어도 게임을 진행할 수 있도록 하는 것이 기본 원칙이며, 지도와 미션북 자체의 디자인도 스토리의 일부로 활용한다.

예를 들어 일반적인 관광지도가 아니라 **낡은 탐험지도, 제빵사의 비밀 수첩, 연구원의 조사 기록지**처럼 각 스토리와 연결된 형태로 제작해 미션키트를 받는 순간부터 세계관에 몰입하도록 한다.

기본 상품은 약 **60~90분**, **2~4인**, **5~7개 내외의 체크포인트**를 중심으로 구성한다. `[ASSUMPTION]`

## 7.2 스토리 콘텐츠 예시

뛰뛰빵빵은 장소마다 독립된 문제를 하나씩 푸는 방식보다, 참가자가 하나의 이야기를 따라 이동하면서 정보를 수집하고 마지막 사건을 해결하는 구조를 기본으로 한다.

참가자는 스토리 속 역할을 부여받고 체크포인트를 이동하면서 새로운 정보를 발견한다. 각 문제에서 얻은 단서는 마지막 미션에서 다시 사용되며, 전체 코스를 완주했을 때 하나의 이야기가 완성되도록 설계한다.

아래 두 스토리는 초기 콘텐츠 방향을 검토하기 위한 **예시안**이며 실제 상품화 과정에서 현장조사와 테스트를 통해 수정한다.

### 스토리 예시 A. 「사라진 제빵사의 마지막 레시피」

대전에서 오랫동안 빵을 만들어온 한 제빵사가 은퇴를 앞두고 자신의 마지막 레시피를 남겼다는 소문이 퍼진다.

그러나 제빵사는 레시피를 한 장의 종이에 남기지 않았다. 그는 자신이 좋아했던 장소와 한밭수목원 곳곳에 레시피를 찾아낼 수 있는 단서를 나누어 남겼다.

참가자는 제빵사가 남긴 오래된 지도와 수첩을 전달받고 사라진 마지막 레시피를 찾아야 한다.

첫 번째 단서를 해석해 장소를 찾아가고, 현장의 조형물·식물·안내시설 등을 관찰하여 숫자와 문자를 얻는다. 각각의 정보는 처음에는 관계없는 것처럼 보이지만 게임이 진행될수록 하나의 레시피로 연결된다.

예를 들어 체크포인트마다 다음과 같은 정보를 획득하도록 구성할 수 있다.

> **밀가루의 양 → 발효시간 → 굽는 온도 → 숨겨진 마지막 재료**

마지막에는 지금까지 얻은 정보를 조합해 제빵사가 남긴 최종 암호를 해결한다. 성공하면 FINAL 봉투에서 제빵사의 마지막 메시지와 레시피에 담긴 이야기를 확인한다.

향후 실제 지역 빵집과 제휴할 경우 게임 종료 후 해당 스토리를 모티브로 한 빵, 완주자 혜택 또는 제휴매장 방문으로 경험을 이어갈 수 있다.

**핵심 경험 흐름**

> 지도 탐색 → 현장 단서 발견 → 레시피 조각 수집 → 암호 해결 → 마지막 레시피 완성 → 지역 빵집·상권 이동

이 스토리는 뛰뛰빵빵이라는 브랜드명과 대전의 **‘빵의 도시’ 이미지, 지역상권 연계 구조**를 직관적으로 보여줄 수 있다는 장점이 있다.

### 스토리 예시 B. 「한밭수목원의 사라진 연구일지」

한밭수목원을 연구하던 한 식물 연구원의 중요한 연구일지가 사라진다.

연구원은 자신의 조사 결과를 한곳에 남기지 않고, 수목원 곳곳에 있는 식물과 공간을 이용해 기록을 나누어 숨겨두었다.

참가자는 연구원의 조사팀이 되어 남겨진 지도와 첫 번째 연구 기록을 전달받는다. 연구일지에는 식물의 특징, 방향, 숫자와 기호 등이 기록되어 있지만 일부 내용이 비어 있다.

참가자는 수목원을 직접 이동하면서 연구원이 관찰했던 장소를 찾아야 한다. 특정 장소에서는 주변 식물이나 안내시설을 관찰하여 빠진 정보를 찾고, 다른 장소에서는 앞선 체크포인트에서 얻은 숫자나 문자를 이용해 다음 암호를 해독한다.

게임이 진행될수록 연구원이 단순한 식물 조사를 넘어 수목원 안의 특정 현상을 추적하고 있었다는 사실이 드러난다.

마지막 체크포인트에서는 지금까지 모은 연구 기록을 하나로 조합해야 최종 장소 또는 최종 암호를 알아낼 수 있다. 성공하면 봉인된 마지막 연구일지를 열어 사건의 결말을 확인한다.

**핵심 경험 흐름**

> 연구일지 수령 → 식물·공간 관찰 → 기록 복원 → 연구원의 이동경로 추적 → 숨겨진 사실 발견 → 최종 연구일지 완성

이 스토리는 **한밭수목원이라는 실제 장소의 특징을 적극적으로 게임에 활용할 수 있다는 장점**이 있으며, 향후 난도를 낮추면 가족·교육형 콘텐츠로도 확장하기 쉽다.

두 예시는 각각 다른 강점을 가진다.

| 구분 | 마지막 레시피 | 사라진 연구일지 |
|---|---|---|
| 핵심 강점 | 대전·빵 브랜드 연결 | 한밭수목원 장소성 강화 |
| 주요 감성 | 로컬·추리·따뜻한 이야기 | 미스터리·탐험·관찰 |
| 상권 연계 | 매우 높음 | 보통 |
| 교육 콘텐츠 확장 | 보통 | 높음 |
| 활용 방향 | 대표 브랜드 콘텐츠 | 수목원 특화 콘텐츠 |

실제 대표상품 개발 시에는 두 방향을 혼합하여 **대전의 로컬 스토리와 한밭수목원의 장소성이 동시에 필요한 이야기**로 발전시키는 방안도 검토한다.

## 7.3 미션 및 문제 설계

문제는 일반적인 상식 퀴즈보다 **해당 장소에 직접 방문해야만 해결할 수 있는 형태**를 중심으로 설계한다.

### 주요 문제 유형
- **관찰형:** 특정 조형물, 안내시설, 식물 또는 공간의 특징을 직접 찾아낸다.
- **지도형:** 종이 지도와 실제 길을 비교하여 다음 위치를 판단한다.
- **암호형:** 현장에서 발견한 숫자·문자를 암호표와 결합한다.
- **조합형:** 여러 체크포인트에서 얻은 정보를 하나로 결합한다.
- **추리형:** 스토리와 단서를 바탕으로 사건의 원인이나 다음 행동을 판단한다.
- **협동형:** 참가자들이 서로 다른 정보나 역할을 나누어 확인한 뒤 결과를 합친다.

예를 들어 다음과 같은 문제를 활용할 수 있다.

- 특정 조형물의 개수를 세어 암호 숫자로 사용
- 안내판에서 특정 조건에 맞는 문자 찾기
- 지도와 실제 길의 방향 비교
- 여러 장소에서 발견한 숫자를 순서대로 조합
- 미션카드의 그림과 실제 풍경 비교
- 앞선 문제의 정답을 다음 문제의 해독키로 사용
- 종이 암호판이나 구멍이 뚫린 카드를 지도 위에 겹쳐 단서 찾기

단순히 `문제 → 정답 → 다음 문제`가 반복되는 구조보다는,

> **관찰 → 기록 → 이동 → 조합 → 추리**

가 반복되도록 한다.

특히 마지막 문제는 앞선 여러 미션의 정답이나 기록을 다시 사용하도록 만들어 처음부터 끝까지 하나의 게임으로 연결한다.

## 7.4 체크포인트·동선 및 운영 설계

초기 대표상품은 약 **5~7개의 체크포인트**를 기준으로 한다. `[ASSUMPTION]`

각 체크포인트는 다음과 같은 동일한 기본 구조를 가진다.

> **① 목적지 추리 → ② 현장 이동 → ③ 공간 관찰 → ④ 단서 획득 → ⑤ 기록·문제 해결 → ⑥ 다음 장소 추리**

가능한 한 별도의 시설물을 설치하지 않고 **이미 존재하는 공간 자체를 게임 장치로 활용하는 것**을 기본 원칙으로 한다.

체크포인트 선정 시 다음 기준을 적용한다.

1. 한밭수목원의 장소적 특징을 보여줄 수 있는가?
2. 실제 현장에 방문해야 단서를 확인할 수 있는가?
3. 계절 변화에도 식별 가능한 요소인가?
4. 시설물 변경이나 철거 가능성이 낮은가?
5. 이용자가 안전하게 머물고 이동할 수 있는가?
6. 일반 방문객의 통행과 수목원 운영을 방해하지 않는가?
7. 식물이나 시설물을 만지거나 훼손하지 않아도 문제를 풀 수 있는가?

운영은 **셀프 플레이 방식**을 기본으로 하며 현장 상주 진행요원의 필요성을 최소화한다. 다만 예약·결제, 키트 배포, 긴급 문의, 분실 대응, 운영시간 변경 등에는 디지털 시스템과 최소 운영 인력을 활용할 수 있다.

힌트는 단계별 카드 또는 봉인형 종이 힌트를 기본으로 하되 실제 테스트를 통해 필요시 최소한의 온라인 보조수단을 검토한다.

야외 콘텐츠인 만큼 우천, 폭염, 한파, 일몰시간, 공사·행사로 인한 동선 변경 등은 운영 단계에서 반드시 고려한다. 특정 장소 하나가 사용 불가능해도 전체 콘텐츠를 중단하지 않도록 대체 체크포인트 또는 문제 교체가 가능한 구조로 설계한다.

## 7.5 초기 MVP 구성 및 검증

초기 단계에서는 여러 스토리와 코스를 동시에 만드는 것보다 **한밭수목원을 기반으로 하나의 완성도 높은 대표 콘텐츠**를 먼저 제작한다.

### MVP 기본안

| 항목 | 초기안 |
|---|---|
| 장소 | 대전 한밭수목원 |
| 핵심 타겟 | 20~30대 친구·연인 |
| 권장 인원 | 2~4인 |
| 콘텐츠 유형 | 추리·스토리형 |
| 플레이 시간 | 60~90분 `[ASSUMPTION]` |
| 체크포인트 | 5~7개 `[ASSUMPTION]` |
| 진행 방식 | 셀프 플레이 |
| 핵심 도구 | 종이 지도 + 미션북 + 펜 + 단서카드 |
| 스마트폰 역할 | 예약·결제·긴급연락 등 운영 보조 |
| 게임 진행 | 아날로그 방식 중심 |
| 엔딩 | FINAL 봉투 및 최종 스토리 |
| 후속 경험 | 지역 빵집·카페·관광지 연계 |

초기 MVP에서는 화려한 장치나 시설물을 만드는 것보다 다음 질문을 우선 검증한다.

- 실제로 재미있는가?
- 참가자가 별도 진행요원 없이 게임을 이해할 수 있는가?
- 지도를 보고 다음 장소를 스스로 찾을 수 있는가?
- 문제 난이도가 적절한가?
- 60~90분 동안 몰입이 유지되는가?
- 어느 구간에서 가장 많이 막히는가?
- 종이키트가 야외 이용에 불편하지 않은가?
- 실제 비용을 지불하고 이용할 의향이 있는가?
- 완주 후 주변 상권으로 이동할 가능성이 있는가?

따라서 뛰뛰빵빵의 초기 제품은 단순한 종이 미션키트가 아니라,

> **하나의 스토리, 실제 장소, 이동 동선, 미션과 추리를 하나의 패키지로 묶어 판매하는 경험형 관광상품**

으로 정의한다.

## 사업계획서 핵심 문장

> **뛰뛰빵빵이 판매하는 것은 지도와 문제지가 아니라, 손에 든 미션키트를 통해 한밭수목원이라는 실제 공간 속 이야기의 주인공이 되는 60~90분의 경험이다.**

## IR PPT 전환 포인트

- 실제 미션키트 이미지 또는 목업을 중심에 배치한다.
- 지도·미션북·단서카드·FINAL 봉투 등 핵심 구성품을 보여준다.
- 체크포인트 하나의 진행 예시를 `찾기 → 관찰 → 기록 → 추리 → 이동`으로 표현한다.
- 스토리 예시는 1개만 대표적으로 노출하고 나머지는 확장 콘텐츠로 제시한다.
- 심사자가 **“실제로 만들 수 있고 바로 테스트할 수 있는 상품”**이라고 이해하도록 구성한다.

### 슬라이드 핵심 메시지 1문장
> **“종이키트를 파는 것이 아니라, 실제 대전의 공간 속으로 들어가는 하나의 이야기를 판매한다.”**
